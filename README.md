# 日当・手当・交通費精算

## 概要

建設・設備・イベント設営・派遣など、現場で働く人や小さな現場チームのための精算計算アプリです。
現場・作業時間・移動・宿泊を記録すると、規程に沿った金額と計算根拠を表示します。
申請・承認は行わず、計算と集計に焦点を当てています。**給与計算ではありません。**

## 主な機能

1. **日当・手当のルール設定（規程）**
   - 適用開始日付きの規程一覧、編集、複製による改定、削除。
   - 日当・半日率・時間外・深夜・早出・休日・特殊作業・宿泊・食事・交通費・日額上限。
   - 距離区分・特殊作業・指定休日の追加と編集、現場マスタの管理。
2. **出勤・移動からの自動計算**
   - 手入力の作業時間、日またぎ、同日の複数現場に対応。
   - 入力中に金額と根拠を表示。前日のコピー、保存パターンによる入力。
   - 作業日に応じた規程バージョンを自動適用。
3. **週次・月次の精算一覧と出力**
   - 末日・15日・20日・25日の締め日、月曜始まりの週次集計。
   - 日別・項目別・現場別合計、前期比、BOM付きCSV2種類、印刷用精算書。
   - 期間の確定・解除、確定時合計の保存、規程変更後の差額表示。

## 計算ルール

| 項目           | ルール                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 日またぎ       | 終了が開始より前なら翌日。開始日の記録として集計。同時刻の開始・終了は無効。                                                          |
| 実働・休憩     | 拘束時間から休憩分を引く。複数現場は実働を合算。時間帯の重複は保存不可。                                                              |
| 深夜の分割     | 前日・当日・翌日の深夜帯との重なりを計算。休憩は通常・深夜に時間比で配分。                                                            |
| 端数           | 時間外は1・15・30分単位で切り捨て・切り上げ・四捨五入。各金額は円未満を四捨五入。深夜時間は表示だけ分に丸め、計算には元の精度を使用。 |
| 日当           | 宿泊、遠方、近距離の優先順で1日分。最大片道距離または遠方指定で判定。半日基準未満の実働なら指定率を乗算。                             |
| 各手当         | 早出・休日・特殊作業・食事は1日1回、宿泊は1泊。休日は開始日の土日と指定日。祝日の自動判定なし。                                       |
| 食事           | 最初の開始から最後の終了までの拘束時間で判定。現場間の空き時間を含む。                                                                |
| 距離区分       | 自家用車は片道距離が収まる最小の区分。往復は2倍。最長区分超は別定額。交通費は現場ごと。                                               |
| その他交通費   | 公共交通は入力実費、会社車両は0円、徒歩・自転車は定額。駐車場・高速代は日別合計に上限を適用。                                         |
| 総額上限       | 全項目合算後に適用。0円は上限なし。上限調整を独立項目として表示。                                                                     |
| 規程バージョン | 作業日以前の最新の適用開始日を選択。開始日の重複、適用規程がなくなる変更は禁止。                                                      |
| 締め日         | 20日締めなら前月21日〜当月20日。末日締めは暦月。2月・うるう年・年またぎに対応。                                                       |
| 現場別集計     | 日別総額を実働時間比で配分。端数は最後の現場に加算し、全体合計と一致させる。                                                          |
| 確定           | 期間内の追加・編集・削除をロック。確定時合計を保持し、規程変更後の差額を表示。承認ではない。                                          |
| 出力           | CSV・印刷は現在の再計算額。印刷には確定時合計と差額も表示。CSVは引用符・改行を処理し、数式を無害化。                                  |

## 既存作品との違い

| 既存作品                           | 既存作品の領域                   | 本作の領域                                   |
| ---------------------------------- | -------------------------------- | -------------------------------------------- |
| 経費精算・承認システム             | 領収書・申請・多段承認・差し戻し | 規程どおりの計算と根拠表示。申請・承認なし。 |
| めぐる日報（訪問・巡回ルート日報） | 訪問先・順路・到着完了・訪問日報 | 距離区分の定額計算。訪問ごとの区間入力なし。 |
| 勤怠管理システム                   | 打刻・有給・勤怠の締め承認       | 時間を手入力し、手当判定だけに使用。         |
| シフト管理システム                 | シフト作成・配置計画             | 実際の作業に基づく手当計算と期間集計。       |

給与計算・社会保険・源泉徴収・振込・請求書作成は扱いません。

## 技術スタック

- Next.js 16 / App Router / TypeScript / React 19
- Tailwind CSS 4 の既存ビルド環境、画面はセクション分割したCSS
- ESLint、Node.js標準テストランナー
- localStorage（`das:v1`）、ブラウザ内CSV生成、`window.print()`
- 外部Webフォント・認証・外部API・メール送信・DBなし

純粋関数は `src/lib/`、画面部品は `src/components/`、ルートは `src/app/` に分離。
テストは既存TypeScriptでメモリ上に変換し、追加パッケージなしで実行します。

## ローカル起動方法

Node.js 22以上を推奨します。コマンドはすべてプロジェクト直下で実行します。

```bash
npm install
npm run dev
```

本番モード：

```bash
npm run build
npm start
```

検証：

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

`next.config.ts` の `turbopack.root` はこのフォルダに固定しています。

## デモデータについて

すべて架空で、実在の企業・現場・個人とは無関係です。
現場8件と、1件ずつ手書きした勤務内容を用意しています。日付は開いた日時の日本時間からの相対で、直近約45日間に割り当てます。
休日出勤・日またぎ夜勤・宿泊出張・半日・複数現場を含み、終了日時が現在より前の記録だけを生成します。
初期締め日は20日。旧規程と、今期開始から5日後に適用する改定規程があります。

21日の未完了時間帯は今期開始直後のため、今期0件になります。
「早朝に今日の記録を生成しない」「終了が未来の記録を生成しない」を優先しています。
それ以外は前期・今期の両方に記録を用意します。
0時台・5時・昼・夕方・23時台、20日・21日・月末・年末年始・うるう日の生成をテストしています。

保存データの構造・数値・日付・時刻・参照を検証し、不正なら既定データに戻して通知します。
初期化ボタンでその時点の日時を基準に再生成できます。保存領域の消去で記録も消えます。
CSVは出力専用で、再取り込み機能はありません。

規程の金額は例であり、実際の就業規則・税務上の扱いは各社で確認してください。
**給与計算ではありません。**
